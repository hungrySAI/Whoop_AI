关联与保留口径

7/30 天按周期起点的 UTC 日期筛选。只显示 WHOOP 明确关联的恢复与睡眠，关联睡眠可起于所选窗口之外；不以同日最近睡眠或较晚小睡替代。

各项保留官方评分与状态，未评分不补零。记录并列不说明因果，也不代表本周期负荷发生在这次恢复之前。

视图使用本机当前保留记录。修正、删除或到期会改变刷新后的结果；关联缺失不保证再次同步就能补齐。训练负荷仍在原趋势中单独查看。
