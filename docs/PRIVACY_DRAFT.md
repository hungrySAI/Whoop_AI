Personal Copilot 是用于本人数据的本地应用。经用户主动授权，可读取 WHOOP 的基本资料、身体测量、
生理周期、恢复、睡眠及训练信息，也可读取用户主动选择的 WHOOP 导出。
用途是本地查看、描述性趋势分析、来源证据追踪和自有训练计划管理。
WHOOP 官方评分直接保留；本应用的统计不冒充 WHOOP 官方评分或医学诊断。

数据保存在用户选定的本机 SQLCipher 加密数据库。数据库密钥、WHOOP client secret 和授权 token
保存在操作系统钥匙串。OAuth 请求和获准数据请求发送到 WHOOP 官方 HTTPS 端点；本应用不会
主动把健康记录发送给模型供应商、广告商、通知接收方或公开服务器。WHOOP 自身的处理遵循其服务政策。

用户在初始化时明确选择允许来源和本地保留天数。每个版本从 API 页面采集或本地文件接收起计算到期时间；
中断续传、重复导入和恢复不会延长已有版本的期限。
在应用运行并打开真实数据库或读取分析时，清理到期的原始/规范记录、相关分析、任务/暂存与受管备份。
用户也可以主动清理来源、撤销尚未执行的计划动作，以及断开 WHOOP 授权。
用户独立撰写的计划按本地记录保留，不因删除 WHOOP 来源而自动移除。

应用不会在退出后自行运行。用户自行复制的文件、原始导出、操作系统快照与备份不在应用清理范围内，
需由用户管理。密钥及数据的跨设备备份尚未实现，钥匙串丢失可能导致数据不可恢复。

用户可随时在本地断开 WHOOP 连接；撤销成功后应用清理该连接的 OAuth 凭据。
断开不会自动删除仍获准保留的本地数据，删除来源需另行操作。
未经新的明确授权，应用不会增加数据接收方、启用真实健康数据的模型分析或公开部署。
