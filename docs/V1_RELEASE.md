## 后续安全提交

先运行 `git status --short` 和 `git diff --cached --stat`，审阅具体文件后再推送。
不要使用 `git add -f` 把运行数据加入仓库；提交内容可被公开访问，必须继续排除真实数据和凭据。
新增样本必须是合成数据，不能仅改文件名或 synthetic 标记。
公开授权仅覆盖代码、文档、合成样本与技术证据；共享真实数据或新增云服务需要另行确定范围。
